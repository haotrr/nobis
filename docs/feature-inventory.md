## 使用边界

- 项目内容继承权限；归档不等于完成或撤权。新内容最多一个项目，旧多项目关联保留核对。详见[资源组织](features/resource-organization.md)、[共同与私密](features/shared-life-design.md)。
- 金额按币种统计，草稿与冲突不入正式合计；退款冲减支出，结算不计收入支出，预计续费不自动入账。收入记录与普通收入流水不自动去重；资产重复／冲突不猜选。详见[报表口径](features/financial-reports.md)。
- 笔记最多 20,000 字、标题 200 字；不是完整 CommonMark，不支持实时逐字协同或本地附件同步；已发布评注不能编辑删除，清单无独立负责人／日期／提醒。详见[笔记](features/documents.md)。
- 普通本地构建不启用云；CloudDebug 已验证同账号日程双向同步及离线并发分支保留，真实双账号未验收。原个人和家庭草稿不自动上传，云版个人私密云随入门连接启用，同账号双向与完整 Minty 个人副本迁入已验证；个人使用独立私有存储，不加入家庭共享。前台自动同步，后台及时性及真实双账号隔离现场验收未覆盖。
- 无应用内 AI 助手、在线 MCP、XPC 服务或 Agent 写入；恢复先到隔离库；合并仅新增当前版本，已有差异须明确保留目标或先解决冲突，完整源历史保存在备份。正式家庭及个人副本迁入结果见验证状态，原 Minty 库保持不变。
