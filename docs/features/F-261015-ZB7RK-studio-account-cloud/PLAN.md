# 账号、Studio 与旧库收敛

## 范围

正式云版以个人私密区和当前 Studio 为日常数据源。一个账号维护名称与头像；Studio 维护名称、成员关系及权限。个人数据不依附 Studio，退出家庭不会删除个人数据。界面继续只允许连接一个 Studio。

## 存储与兼容

- 已核验 Apple ID 对应的账号资料保存于个人快照 `account` 可选字段，旧快照可读取；资料版本不可变，离线分支保留，按修改时间和版本 ID 确定展示值。家庭只接收账号名称与头像，不接收私密记录或草稿。
- `SpaceRepositoryRouter` 支持多条已授权空间路由，一次业务写入仍只能改变一个存储。`StudioMembership` 显式记录账号、Studio 和角色；当前 Studio 筛选不泄漏其他 Studio 的记录。真实多家庭 CloudKit 生命周期尚未开放。
- 笔记／评注草稿在个人区按设备和草稿键分别保留，删除使用带时间的空载荷；不同设备不覆盖。用户可恢复可访问空间的草稿，已有不同本机草稿时拒绝覆盖。仅同步完整落盘草稿，不包含尚在中文组词中的输入。
- 云版新用户不创建本地个人／家庭草稿库。旧库保留供备份与恢复，退出日常路由；无云配置的开发隔离模式继续用于测试。

## 迁移与风险

先备份源快照、目标快照及草稿，再按现有恢复合并流程预览来源键、关联和成员映射；冲突、未知旧成员和旧空间未保存草稿阻断完成，不能猜测或静默丢弃。重复执行仅加入缺失当前版本，原修订历史留在备份；源库不删除。当前 Mac 旧两库和草稿均空，无需重导 Minty。

应用更新必须保留既有容器和身份。迁移前后比较所有业务修订、财务字段和数量，资料变化不重写账务。旧版本不理解新增账号字段，真实验收需将参与设备更新后再确认收敛。账户资料同一时刻并发修改保留两个版本；展示选择不等于自动解决业务冲突。

## 验证

账号版本合并／旧格式兼容、资料与业务保存隔离、三个存储路由及当前 Studio 范围、跨库写入拒绝、草稿冲突与删除收敛、云端新用户不建本地库、旧本地数据不混入查询。双平台构建、设置页入口和资料编辑验证；Mac／iPhone 分别备份与核对，不用测试成功替代双账号验收。
