# 个人私密云同步与 Minty 个人副本迁入

## 目标与授权

用户授权实现仅 haotrr 可见的个人 iCloud，同一界面展示 D&H Studio 与个人数据；验证后导入最新个人副本，原 Minty 库不改。家庭数据已正式导入，保持原有修订与共享关系。已有 UI／设计未提交改动保留，不改第三方。

## 方案

独立 CloudKit private database 自定义 zone，不创建 CKShare，不接入家庭 Core Data 关系图。按已核验 Apple ID 隔离本地缓存，账号变化立即使旧 repository 失效。原有本地私人空间不自动上传。新增目标优先个人云空间，浏览仅自己包含本地与云端。

首版单 CKAsset 快照，校验完整空间／修订／审计后发布，以 change tag 乐观并发保存，冲突合并不可变历史而不覆盖分支；40 MB 容量门槛。前台定期、回到前台及保存后同步，后台送达不作保证。后续大库增量传输另行优化。
