# 共同与私密

默认共同生活，少量内容仅自己可见；界面统一不合并物理存储，不自动扩大旧数据权限。云端实际验收见[验证状态](../verification.md)。

## 创建与访问

| 场景 | 规则 |
| --- | --- |
| 全局新建 | 默认共同，无项目合法；无可写共同目标时提示原因，不静默改存私密 |
| 项目内容／子项目 | 继承项目权限；清空所属项目保留原可见性；跨范围修改须分享预览或阻止 |
| 私密记录 | 仅拥有者读写；其他成员的搜索、计数、报表、提醒和错误中不泄露存在性 |
| 共同记录 | 已核验成员按授权访问；本地占位称呼不代表已接受邀请 |
| 历史／回收站 | 继承原访问权限；归档删除不改变可见性 |
| 引用 | 同范围引用不改变项目或授权；退款继承原支出，续费任务继承订阅，计划项继承项目 |

不提供逐字段权限、访客或项目级停止共享，也不能把共同内容直接改成私密。退出／撤权不能收回对方已导出的文件；锁屏通知不承诺完全隐藏私密预览。

## 私密分享

1. 预览当前完整记录图及引用；预览绑定修订集合，来源变动后重新核对。
2. 冲突、依赖缺失或不能合法发布的财务记录阻止分享；不猜补账单／退款／计划项关系。
3. 创建新共同 ID，只发布确认的当前内容，不上传私密修订、审计、迁移包或原评注；来源映射仅保留在本人侧。
4. 目标保存后，来源退出活跃列表及合计，保留只读凭据；失败保留原状态，按操作 ID 和持久阶段回执恢复，不承诺跨库事务原子性。
5. 本地保存或云端导出完成不等于对方收到。首版为完整集合分享，避免复制活跃账单重复计算。

## 财务归属

- 可见性、操作者、付款人、消费归属、收入归属和资产持有人分别记录；旧未知归属不自动认领为创建者。
- 共同报告只含共同可见记录，不表示共同产权；“全部”是本人视角，不保证双方一致。导出和 CLI 携带范围，各币种独立。
- 资产按持有范围与币种取截至日最新完整快照；同日重复／冲突提示核对。旧家庭整体余额与分人余额分别展示，不相加；切换日期及完整对账向导待实现。
- 同一收入只选月度记录或普通流水一种方式，详见[财务报告](financial-reports.md)。

## 旧数据与存储

| 原数据 | 保留方式 |
| --- | --- |
| 个人空间 | 原 ID、修订和权限留在本地，不自动上传；尚无个人 iCloud 同步 |
| 家庭草稿 | 不冒充云家庭；云家庭存在时进入只读待迁入入口，不混入共同报告 |
| 已核验云家庭 | 沿用成员映射与访问授权，失权清理专用云缓存 |
| 多项目记录 | 保留原关联待核对，不猜选项目、复制金额或迁移权限 |
| 收入／资产 | 原金额与范围保留，未知归属和旧整体资产需核对 |

无云家庭时，本地家庭草稿为共同默认。读写按记录实际来源路由；共同库不存私密业务、历史或引用。恢复先进入隔离库，不随意替换私密拥有者；旧家庭成员映射迁入、共享升级和个人云同步见[后续计划](../roadmap.md)。
