# 笔记与评注

正文、评注与文件交换规则。

入口：主导航「笔记」→ 新建笔记 → 选择共同／仅自己及可选项目 → 直接排版编辑 → 保存。支持分组、置顶，按最近修改排列，支持标题与正文搜索、归档和回收站。项目关联继承所在空间边界。

| 能力 | 当前行为 |
| --- | --- |
| 正文 | Markdown 纯文本，最多 20,000 字；标题最多 200 字 |
| Markdown 阅读兼容 | 1–6 级标题、粗体、斜体、行内代码、链接、无序／有序列表、可勾选待办、基础表格、独占一行的 HTTPS 图片、引用、围栏代码块、分隔线 |
| 限制 | 不完整实现 CommonMark；嵌套列表与 HTML 不做专门渲染；可视化编辑器直接显示 HTTPS 图片，阅读渲染按需加载，不提供本地附件上传；链接仅允许 http、https、mailto |
| 保存 | 正文与评注自动保留本机草稿，显式保存／发布；关闭时可保留或放弃；恢复保留原始版本，遇到新修订时拒绝覆盖 |
| 协作 | 沿用家庭空间当前双人成员与读写权限，不新增公开链接或外部成员邀请 |
| 评注 | 整篇评注、选取原文引用或粘贴引用；每条最多 4,000 字，引用最多 2,000 字；作者和发布时间来自首个修订 |
| 回复 | 一级线程，可多次回复；已解决线程需先重新打开；发布内容不支持改写或删除 |
| 已解决 | 有写入权限的成员均可解决／重新打开根评注，保留操作历史 |
| 引用 | 发布时核对原文；以后保留引用快照，不自动定位、不随正文移动 |
| 隐私 | 同空间文档关联才可留言；个人文档的评注不会随正文副本分享；历史评注留在来源空间 |
| 同步 | 复用现有 Core Data / CloudKit 修订与审计；留言为独立记录，正文编辑不覆盖评注；不提供实时光标或逐字协同 |

## 编辑与草稿

可写笔记打开即在主内容区直接编辑，没有编辑／预览切换。宽屏正文与评注并排，窄屏评注在下方统一滚动。输入 Markdown 符号不实时转换，日常排版使用工具栏。

正文与评注分别保留本机草稿；发布评论不保存或覆盖正文。保存失败保留输入，恢复草稿核对原版本；关闭时可保留或放弃。失去空间访问时按空间清理草稿。组词期间不把临时拼音发布为正式正文，放弃草稿后关闭回调不能重新写入。

列表显示他人评注未读数，展开评注后本机标记已读，不跨设备同步。最后编辑者与时间单独显示。

## 清单与交换

保存的 Markdown 清单自动进入今天／安排／所属项目待办，双向勾选同一正文；未保存草稿、代码示例不参与。来源定位和版本检查规则见[资源组织](resource-organization.md)。

UTF-8 `.md` 导入追加到当前草稿，避免覆盖；导出正文不包含评注或外部图片文件。正文与评注复用现有记录、修订、权限与持久化；备份版本统一见[架构](../architecture.md)。

## 快捷键

快捷键按当前页面或正文焦点生效；外接键盘真机覆盖范围见[验证状态](../verification.md)。

| 快捷键 | 操作 |
| --- | --- |
| ⌘N | 笔记列表中新建笔记 |
| ⌘Return | 评注编辑器中发布评注 |
| ⌘S | 编辑器中保存并继续编辑；保存后可继续撤销 |
| ⌘B / ⌘I | 对当前编辑区域应用粗体／斜体 |
| ⌘K | 为选区设置链接地址 |
| ⌘F | 正文系统查找栏；Mac 栏内可展开替换 |
| ⌘G / ⇧⌘G | Mac 正文下一个／上一个匹配 |
| ⌘O | 编辑器中导入 Markdown 文件 |
| ⇧⌘S | 阅读页导出 Markdown |
| Esc | 关闭编辑器；有未保存内容时先选择保留草稿／放弃／继续 |

撤销／重做、剪切、复制、粘贴、全选、按词／行移动和选取沿用原生文本控件。格式化不会截断 Emoji 的 UTF-16 代理对，中文输入法组合期间不处理格式快捷键。未占用 Mac 的 ⌘E 文本查找惯例。编辑器问号面板可查看快捷键说明。

## 可视化内容块

正文工具栏「＋」可插入表格、图片或代码块，直接在主页面操作，无编辑／预览切换。

| 内容 | 操作 |
| --- | --- |
| 表格 | 点击单元格输入，保留粗体／斜体／链接；菜单添加行列、删除末行末列；窄屏横向滚动 |
| 图片 | HTTPS 图片直接显示；编辑说明；展开「替换图片与设置」修改地址和标题；失败显示占位提示 |
| 代码块 | 等宽字体直接编辑，语言标签可修改；不显示围栏标记，代码中的 Markdown 符号按代码原样保留 |
| 内容菜单 | 删除整块、在下方继续写正文、撤销和重做 |

正文、表格单元格与代码内容使用共享撤销记录。⌘Z／⇧⌘Z 可撤销／重做文字及表格结构；格式指令仅发给当前选中的正文或单元格。查找仍使用当前原生文本区域的系统查找。

底层仍为 Markdown；未编辑的内容块保留原始文本，编辑后的块规范序列化。支持管线转义、单元格换行、图片说明／标题、长代码围栏；代码里的示例清单不会进入待办系统。图片目前使用 HTTPS 地址，未增加本地附件存储或同步。

## 验证边界

本地交互与自动测试见[验证状态](../verification.md)。当前不提供逐字协同、本地附件同步或已完成的真实双账号验收。
