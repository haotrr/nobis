# 笔记与评注

正文、评注与文件交换规则。

入口：主导航「笔记」→ 新建笔记 → 选择共同／仅自己及可选项目 → 直接排版编辑 → 保存。支持分组、置顶，默认按最近修改排列，也可选择最早修改优先或标题排序；置顶始终优先，排序偏好保存在本机。支持标题与正文搜索、归档和回收站。项目关联继承所在空间边界。

| 能力 | 当前行为 |
| --- | --- |
| 正文 | Markdown 纯文本，最多 20,000 字；标题最多 200 字 |
| Markdown 阅读兼容 | 1–6 级标题、粗体、斜体、行内代码、链接、无序／有序列表、可勾选待办、基础表格、独占一行的 HTTPS 图片、引用、围栏代码块、分隔线 |
| 限制 | 不完整实现 CommonMark；Mac 支持嵌套列表、提示块与折叠，iOS 不专门渲染这些扩展；HTML 不专门渲染；可视化编辑器直接显示 HTTPS 图片，阅读渲染按需加载，不提供本地附件上传；链接仅允许 http、https、mailto |
| 保存 | 正文与评注自动保留本机草稿，显式保存／发布；关闭时可保留或放弃；恢复保留原始版本，遇到新修订时拒绝覆盖 |
| 协作 | 沿用家庭空间当前双人成员与读写权限，不新增公开链接或外部成员邀请 |
| 评注 | 整篇评注、选取原文引用或粘贴引用；每条最多 4,000 字，引用最多 2,000 字；作者和发布时间来自首个修订 |
| 回复 | 一级线程，可多次回复；已解决线程需先重新打开；发布内容不支持改写或删除 |
| 已解决 | 有写入权限的成员均可解决／重新打开根评注，保留操作历史 |
| 引用 | 发布时核对原文；以后保留引用快照，不自动定位、不随正文移动 |
| 隐私 | 同空间文档关联才可留言；个人文档的评注不会随正文副本分享；历史评注留在来源空间 |
| 同步 | 复用现有 Core Data / CloudKit 修订与审计；留言为独立记录，正文编辑不覆盖评注；不提供实时光标或逐字协同 |

## 列表管理

Mac 右击笔记卡片（iOS 长按）可重命名与调整分组（选择已有分组、新建或清空）、置顶／取消置顶、移动到项目、移出项目（选择“无项目”）、归档／取消归档和移入回收站。删除前显示笔记标题并确认，可从现有回收站恢复。排序在列表顶部及上下文菜单均可选择。卡片显示所属项目与归档标识；关键词、分组或置顶筛选无结果时可一键清除这些筛选，保留可见范围。

移动只列出同一空间内未归档且无冲突的项目，不跨共同／私密边界。只读或有冲突的笔记禁用修改操作；所有操作沿用修订与并发检查，不覆盖现有草稿。

## 编辑与草稿

Mac 可写笔记默认在主窗口内编辑；点击编辑器上方“在独立窗口打开”才弹出，列表右键也提供此入口。弹出窗口可调整大小并选择“窗口始终置顶”。切换时移动同一编辑器，保留当前草稿和撤销历史，组词期间暂时禁用弹出。同一笔记再次打开只激活已有窗口，正文、草稿和撤销栈不重建；新建笔记保存后仍复用该窗口。主页面保留管理与评注。关闭按钮、⌘W 与编辑器关闭操作共用草稿确认，⌘S 保存后继续编辑；关闭后恢复草稿正文，原生撤销历史只在当前窗口存续期间保留。iOS 继续在主内容区直接编辑，没有编辑／预览切换；宽屏正文与评注并排，窄屏评注在下方统一滚动。Mac 使用内置 MDTextKit 实时原位排版，光标进入对应结构时显露 Markdown 标记；iOS 使用 MDTextKit UIKit 内核实时排版，语法标记保留可编辑并以次要颜色显示，日常排版也可使用工具栏；表格、图片和代码继续使用触屏内容块布局。组件源码和维护入口见 [MDTextKit](../components/mdtextkit.md)。

正文与评注分别保留本机草稿；输入在 200ms 窗口内合并并串行后台落盘，持续输入不无限延后写入，落盘完成前显示正在保留。关闭、离开页面与切后台补写最新内容，保存／发布或放弃时取消待写内容并排空已提交写入，避免旧草稿复活。发布评论不保存或覆盖正文。保存失败保留输入，恢复和保存草稿时核对原版本：若已保存版本仅发生名称、分组、项目、置顶或归档属性变化，按字段合并独立变化，保留草稿正文；正文或其他内容变化、同字段不同修改、删除或多头冲突仍拒绝自动合并。管理操作不写草稿文件；关闭时可保留或放弃。失去空间访问时按空间清理草稿。组词期间不把临时拼音发布为正式正文，放弃草稿后关闭回调不能重新写入。

列表显示他人评注未读数，展开评注后本机标记已读，不跨设备同步。最后编辑者与时间单独显示。

## 清单与交换

保存的 Markdown 清单自动进入今天／安排／所属项目待办，双向勾选同一正文；未保存草稿、代码示例不参与。来源定位和版本检查规则见[资源组织](resource-organization.md)。

UTF-8 `.md` 导入追加到当前草稿，避免覆盖；导出正文不包含评注或外部图片文件。正文与评注复用现有记录、修订、权限与持久化；备份版本统一见[架构](../architecture.md)。

## 快捷键

快捷键按当前页面或正文焦点生效；外接键盘真机覆盖范围见[验证状态](../verification.md)。

| 快捷键 | 操作 |
| --- | --- |
| ⌘N | 笔记列表中新建笔记 |
| ⌘Return | 评注编辑器中发布评注 |
| ⌘S | 编辑器中保存并继续编辑；保存后可继续撤销 |
| ⌘B / ⌘I | 对当前编辑区域应用粗体／斜体 |
| ⌘K | 为选区设置链接地址 |
| ⌘F | 正文系统查找栏；Mac 栏内可展开替换 |
| ⌘G / ⇧⌘G | Mac 正文下一个／上一个匹配 |
| ⌘O | 编辑器中导入 Markdown 文件 |
| ⇧⌘S | 阅读页导出 Markdown |
| Esc | 关闭编辑器；有未保存内容时先选择保留草稿／放弃／继续 |

撤销／重做、剪切、复制、粘贴、全选、按词／行移动和选取沿用原生文本控件。格式化不会截断 Emoji 的 UTF-16 代理对，中文输入法组合期间不处理格式快捷键。未占用 Mac 的 ⌘E 文本查找惯例。编辑器问号面板可查看快捷键说明。

## 可视化内容块

正文工具栏「＋」可插入表格、图片或代码块，直接在主页面操作，无编辑／预览切换。iOS 正文按实际高度跟随页面滚动；插入在光标处（有选区时在选区末尾）拆分正文并保留文字，表格／代码焦点则在所在块后插入；新内容自动获得焦点，撤销恢复原文与选区。Mac 为统一文本流，表格提供单元格和行列菜单；图片地址、说明与代码语言通过原位 Markdown 修改。下表中的独立字段和块菜单为 iOS 的块编辑方式。

| 内容 | 操作 |
| --- | --- |
| 表格 | 点击单元格输入，保留粗体／斜体／链接；菜单添加行列、删除末行末列；窄屏横向滚动 |
| 图片 | HTTPS 图片在稳定 4:3 区域内完整等比显示，加载／失败不改变正文位置；编辑说明；展开「替换图片与设置」修改地址和标题；失败显示占位提示 |
| 代码块 | 等宽字体直接编辑，语言标签可修改；不显示围栏标记，代码中的 Markdown 符号按代码原样保留 |
| 内容菜单 | 删除整块、在下方继续写正文、撤销和重做 |

正文、表格单元格与代码内容使用共享撤销记录。⌘Z／⇧⌘Z 可撤销／重做文字及表格结构；格式指令仅发给当前选中的正文或单元格。查找仍使用当前原生文本区域的系统查找。

底层仍为 Markdown；未编辑的内容块保留原始文本，编辑后的块规范序列化。支持管线转义、单元格换行、图片说明／标题、长代码围栏；代码里的示例清单不会进入待办系统。图片目前使用 HTTPS 地址，未增加本地附件存储或同步。

## 验证边界

本地交互与自动测试见[验证状态](../verification.md)。当前不提供逐字协同、本地附件同步或已完成的真实双账号验收。
