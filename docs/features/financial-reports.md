# 收入、资产与财务报告

入口：**账本 → 收入、资产与财务报告**。选择年、月，打开“年度报告”查看全年。报告沿用账本的共同／仅自己／全部范围，按来源空间读取。报告可打开本期流水，保留年份／月份与可见范围。

账本“流水收入”只统计普通收入流水，不含月度及非月度收入记录；报告“收入”按下述完整口径汇总，并显示月度税后到账、非月度税后到账及流水收入。账本提供年月快捷选择、按月分组及分币种小计；小计仅统计当前筛选命中的记录，草稿与冲突不计入。

## 交易与分摊

金额用整数最小货币单位；超精度拒绝，累计检查溢出。只记收支允许保留零元支出，不产生成员欠款；零元不用于收入、退款或成员结算；结算模式支持平均／固定分摊，平均分摊余数按成员 UUID 稳定分配。

已确认账单可修改标题、分类、项目、计划项、消费归属和备注；金额、币种、日期、付款人、账户及分摊变更须作废后重记。退款须关联同币种、同付款人、同记账模式的已确认原支出，累计及各成员退款不得超过原额；原支出作废前先作废关联退款。

计划项须属于所选项目且币种一致；仍有账单引用时不可删除。默认只记收支，兼容记录缺少模式字段时沿用成员结算，避免改变旧余额。

## 收入记录

保存年份、月份（0 表示非月度）、收入类型、币种、税前、税后到账、可空税额。没有虚构发生日，不自动创建 transaction 流水。税额留空为未知，明确填零才表示零；税前减税后可能包含社保、公积金等扣款，不推断为税额。

月报收入 = 该月所有有效月度收入的税后金额 + 已确认普通收入流水。**同一笔收入只选一种录入方式**；本版本不按姓名、金额或类型推测两种记录是否重复。允许同月同类型多笔收入，按真实记录相加。修改记录形成审计修订；回收站记录不进入统计。

非月度收入只计入所属年份的年报，不计月报及逐月图表；年报收入可高于十二个月之和。详情、编辑和导入预览显示“非月度”，不显示“0 月”。报告 JSON／CSV 单列 `nonMonthlyNet`／`non_monthly_net_income`。

## 资产与负债

每个快照是来源空间内某持有范围、某日、某币种的完整余额，包括：存款、投资理财、股票、房产、借出款、公积金、房贷、信用卡负债、其他负债。金额为非负数；未持有填零，净资产可以为负。

- 总资产 = 前六项合计；总负债 = 后三项合计；净资产 = 总资产 − 总负债。
- 期末按持有范围和币种取不晚于该月末／年末的最新快照，不把不同日期快照相加，不用未来快照回填过去。
- 最新日期存在多条同持有范围、同币种快照，或该日期有修订冲突，显示待核对，不猜选一份，不回退旧余额冒充最新。
- 净资产走势图展示当年实际完整快照点，并有可读金额列表；不插值补造缺失日期，重复／冲突点不绘图。
- 资产变化不是现金收入，也不替代交易账本。个人／共同持有通过快照归属区分，可见性另行控制。

## 报表口径

净支出 = 已确认支出 − 退款。退款进入其实际发生月份，成员结算不计为支出或收入。结余 = 收入 − 净支出。分类和消费归属沿用账单记录的字段。

各币种独立展示，无汇率转换。草稿和冲突排除，并显示未计入数量；同一冲突跨月时，两个月都标为待核对。税前及已知税额单列，同时显示税额缺失条数。年报用分组柱形图展示逐月收入与净支出，并提供精确金额列表。无记录与明确零元分别显示；未来月份不绘制，当前月流水截至今天。非月度收入留在年度汇总，旁边说明年度合计与逐月合计的差额来源。年报汇总仍包含所属年度已录入的记录，可能包含未来日期流水。

报告 CSV 包含汇总、分类／归属、缺失税额和待核对数量。年报导出同时包含全年及 12 个月，各行以 year/month/currency/metric 区分。没有数据时仍导出 report_status 行。CSV 是核对报告，不是可恢复备份；完整历史使用设置中的 JSON 备份。

## 图表与历史浏览

- 分类按净支出降序显示水平条形图，默认前六类，可展开全部；退款导致的负值保持可见。点击分类金额进入仅支出／退款的流水，保留期间、币种和财务范围。
- 图表币种可筛选，各币种不叠加。点选条目显示精确金额，纵向拖动仍滚动页面；月度及计划项逐条提供中文辅助功能描述，同时保留可读列表及明细入口；收入与资产长历史默认折叠。
- 跨年对比分开呈现已记录年度收入（含非月度）和截至各年同月同日的同期净支出。显示收入及支出的记录月份数，缺失数据不填零、不计算误导性的同比百分比。
- 资产图表截止于所选期间末与今天的较早日期；按来源、持有范围和币种展示实际快照点、资产／负债结构及任意两次有效快照的分项增减。比较注明日期与间隔天数，余额变化不视为投资收益。
- 项目显示预算与实际净支出的条形对比，超支不截断为 100%；零预算不计算比例。计划项并列展示计划／实际，点击进入该计划项费用；未关联计划项的费用仍计入项目总额。

## 订阅成本

预计成本只统计当前 active 且无冲突的订阅，paused 单独计数。按当前价格／周期折算：月周期按 12 个月、年周期按 1 年、日周期按 365 天、周周期按 365/7 周。分币种 Decimal 汇总，最后四舍五入到最小货币单位。这是折算预算，不是精确扣款日历，也不是过去期间的订阅价格快照。

价格未知项不按零元服务解释，显示未计入项数。期间实际净支出来自所选月／年已确认的关联支出及退款；退款未单独关联订阅时沿原支出关联查找。预计金额不会写成实际账单。

## CLI

导入映射见[迁移指南](../guides/minty-migration.md)，兼容格式见[架构](../architecture.md)。

```sh
swift run nobis finance.report --export /绝对路径/备份.json --space 空间UUID --year 2026 --month 10
swift run nobis finance.report --export /绝对路径/备份.json --space 空间UUID --year 2026
swift run nobis subscriptions.costs --export /绝对路径/备份.json --space 空间UUID --year 2026 --month 10
```

原 `ledger.summary` 仍只汇总普通交易流水；包含月度收入的报告使用 `finance.report`。CLI 不直接读取 App 数据库，不写入任何财务记录。

## 可见范围与归属

账本默认共同范围，可切换仅自己或我可见的全部，列表与报告导出携带同一范围。资产快照包含持有范围，原快照视为原整体范围／待确认；各范围单独取最新值与绘图，不将旧整体余额与分人余额相加。收入归属可选择成员，未知旧记录保留待确认。私密分享完成后原来源保留历史，不进入活跃报告。

## 归属与资产核对

设置或报告的“成员与资产核对”支持按空间、类型、名称／期间筛选后批量确认财务归属。收入必须归到明确成员；资产可归到成员或共同持有。Minty 没有提供这些持有信息，保持待确认，不用记录人、消费归属或账本名称推断。调整创建新修订并保留来源指纹，重导不会覆盖已确认归属。旧本地成员到目标家庭的身份映射是独立预览流程，不会改变访问权限或重写历史作者。

资产比较要求旧整体与所选分项同日期、同币种，每个持有范围没有重复或冲突。逐项展示旧整体、所选分项合计及差额；九项一致才显示金额一致，净资产相同不能替代逐项一致。对账为只读，金额一致也不证明分项范围没有遗漏或重叠，不将旧整体与分项加总为报告资产。
