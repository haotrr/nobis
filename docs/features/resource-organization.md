# 资源组织

项目、笔记、安排与账本的组织规则。

页面功能见[功能清单](../feature-inventory.md)，这里定义跨资源组织规则。

## 笔记清单就是待办

在笔记正文输入 `- [ ] 内容` 或 `1. [ ] 内容`，保存后自动显示在待办。勾选待办修改同一份 Markdown；正文编辑并保存的清单状态也反映到待办。已完成项可通过“显示已完成”查看和重新打开。点击来源打开笔记并定位高亮该行。

缩进清单也参与汇总；代码块中的示例不参与。相同文字的清单按来源行区分，正文修订变化时拒绝旧点击，防止行号偏移误改。删除清单行、删除或归档笔记后不保留独立任务；恢复笔记后重新投影。冲突笔记先核对版本。未保存草稿不会被当成正式待办，也不会发布给共同成员。

## 归属与项目

共同／仅自己决定谁能看到；所属项目决定围绕哪件事组织；笔记分组只用于整理。无项目内容是正常状态。每个新内容最多一个所属项目，旧多项目关联继续保留核对。

项目内新建自动带上项目及其可见范围。项目“加入已有内容”列出同范围的无项目资源；原本已有项目的内容从其编辑页调整。项目归档明确提示未完成事项仍保留，不自动完成待办、归档笔记或删除账单。

项目和笔记可置顶，在今天页也可找到。名称头像仍用于显示资源归属；负责人、创建者和付款人保持独立角色。

## 查找与引用

今天页放大镜打开全局搜索（Mac ⇧⌘F），搜索标题、正文、资源类型和笔记分组；多个空格分隔关键词须全部匹配。只检索当前有权访问的内容，含归档资源，不含回收站及已分享来源。

编辑页“相关内容”可关联同范围其他资源，详情显示正向和反向引用；引用不改变所属项目或访问权限。被删除的引用不显示，恢复后重新可见。分享私密内容时，引用必须处于同一完整预览集合内；不自动扩大分享范围。

日历区分全天／定时日程、待办截止和预计续费。跨天日程在涉及日期显示；截止日不是已安排的执行时间。笔记清单没有独立日期，保留在待办的“笔记清单”分区。

## 兼容与边界

兼容格式见[架构](../architecture.md)，设备与同步验收见[验证状态](../verification.md)。

笔记分组名称最多 40 字，相关内容最多 30 条，不得引用自身或直接引用评注。分组通过编辑页设置名称；暂无独立空分组或批量重命名。资源引用暂不跨共同／私密范围；循环引用的整组分享会被阻止，需先调整引用。清单的独立负责人、提醒和到期日期尚未提供。
