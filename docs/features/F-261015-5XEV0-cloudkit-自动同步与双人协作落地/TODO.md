# CloudKit 自动同步与双人协作落地

## 目标与边界

- 用户授权推进自动同步及两人协作，开发者团队与容器由用户自行配置。
- 先验同账号 Mac／iPhone 的新云家庭，再验不同账号邀请、双向写入、离线、并发、删除和撤权。
- 保留现有个人和家庭草稿；不自动上传、迁移或扩大权限，不修改第三方源码，不发布生产 schema。
- 私密跨设备同步及旧数据迁入尚未实现，不属于本次已完成能力。需要后续明确迁移与私密存储方案。

## 调研与方案

现有 CloudFamilyController、CloudFamilyRepository 与系统邀请已经接入。普通 Scheme 不含云配置；仓库缺少本机团队／容器配置。连接失败只设置退避时间但未排队重试；导出完成只记录时间，可能错过重新核验共享关联。

补齐暂时错误重试、服务端退避和导出后刷新；沿用现有身份验证、独立云库及撤权机制。先以新建测试数据验收，不借用正式库证明云同步。
