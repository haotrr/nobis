# Nobis 产品方向

**A Family Studio · Pro nobis · 为了我们。**

Nobis 面向两位共同生活的成年人，集中管理生活事务和财务。没有 AI 时也应完整可用；未来的 AI 入口复用同一业务规则，不成为数据保存或日常操作的前提。

## 产品原则

- 默认共同生活，少量内容仅自己可见；不因关联项目、搜索或接入 AI 扩大权限。
- 以项目组织旅行、搬家等具体事情，以笔记记录内容，以安排管理时间，以账本记录实际收支。
- 事实与计划分开：预计续费不是扣款，预算不是支出，资产变化不是收入。
- 原生操作直接可用，错误保留输入，冲突可核对，数据可导出和恢复。
- 两位成员能明确知道内容属于谁、谁能看见，以及当前是否只是本机保存。

## 概念

| 概念 | 用途 |
| --- | --- |
| Space | 个人或家庭的访问与存储边界，不是旅行项目 |
| Project | 空间内的生活项目，关联任务、日程、笔记、预算和费用 |
| Member | 成员身份；与负责人、付款人、收入归属等业务角色分别处理 |
| Record / Revision | 业务记录及不可变修订，保留变更与冲突 |

当前功能统一见[功能清单](feature-inventory.md)，页面与组织规则见[资源组织](features/resource-organization.md)，视觉与交互见[DESIGN](../DESIGN.md)。

## 未来方向

| 方向 | 产品要求 |
| --- | --- |
| 可靠双人共享 | 通过真实双账号、离线、并发及撤权验证，才能宣称双人可用 |
| AI 辅助查询与操作 | 答案可追溯，写入先预览批准，不直连数据库或自动执行支付 |
| 共同决策 Consilium | 保留议题、选项、双方意见、结论与复盘，不将沉默视为同意 |
| 生活记忆 Memoria | 区分记录事实和推断，保留来源，允许纠正、过期与撤回 |
| 文件与连接 | 在明确授权、恢复和隐私边界后增加，不预设已有附件同步或外部账号接入 |

这些方向不代表已实现，也不承诺固定版本或日期。技术条件见[技术演进方案](proposal-detailed.md)，实际排期与待办只维护在[后续计划](roadmap.md)。
