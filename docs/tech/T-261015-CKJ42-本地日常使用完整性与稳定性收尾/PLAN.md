# 本地日常使用完整性与稳定性收尾

## 目标与范围

按本地 v0.1 日常使用闭环收尾：录入编辑、笔记草稿与清单、安排订阅、财务导入报表、备份恢复、提醒和规模性能。保留已有未提交的评注已读修复。以代码和隔离回归证明结果，不将覆盖率估算当作验收。

不启用云同步、不修改正式业务库、不执行正式迁入；不扩展 XPC/AI、专门无障碍、真实双账号或最低系统专项。未获本轮交付指令前不提交、推送或安装正式应用。Vendor 和生成工程不改。

## 方案

1. 整理已有功能测试与缺口，对已覆盖闭环复用回归，新增失败场景而非重复实现功能。
2. 文件状态：已读标记保存成功后更新，失败可重试。
3. 日期输入：反序列化验证日期，日期加减不受设备时区跳日影响，阻止畸形本地／导入数据进入强制解包路径。
4. 刷新一致性：记录与统计作为一组发布；本地临时读取失败保留最后成功结果并明确提示，权限失败清除缓存。
5. 提醒：刷新统一触发调度，更新只移除过期计划，失败不预先清空仍有效提醒；隔离测试不申请权限、不发送系统通知。
6. 备份规模：按修订图一次拓扑检查环，复用关联索引，消除长历史和大量关联的重复扫描；保持原校验规则。
7. 隔离回归与双端构建，形成测试矩阵，明确真实系统送达、屏幕交互及最低系统的证据界限。

## 风险与回滚

不更改持久化 schema、记录权限或业务计算口径；优化前后使用相同快照核对。新增失败恢复测试覆盖隐私失权清除、数据不变与重试。仅修改源码，可按文件回退；不使用用户库实验。
