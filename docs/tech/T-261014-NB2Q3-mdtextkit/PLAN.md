# MDTextKit 源码集成方案

## 目标与授权

用户授权将 MDTextKit 源码直接纳入 Nobis，方便后续优化。完成实现与合理验证；用户随后授权提交并安装 Mac 正式包。不推送，不修改正式业务数据。

## 方案

- 在 `Vendor/MDTextKit` 保留 0.1.2 完整源码、测试、Demo 和 MIT 许可；根包使用本地路径，Mac 条件依赖。
- 上游 AppKit 编辑器调整为 macOS 14 部署声明；iOS 17 沿用现有原生块编辑，不假称已移植 UIKit。
- Mac 完整正文编辑与普通只读展示接入 MDTextKit；带清单行定位／勾选回调的阅读仍保留原实现。
- SwiftUI 适配层负责主题、格式指令、HTTPS 图片和链接白名单；业务草稿、保存、修订、评注与清单投影保持现有边界。
- 修复组词重排与临时正文回传、表格延迟回写及撤销、只读表格交互；维护补丁说明，不复制 Noto 的 AGPL 代码。

## 验证

完整 Nobis 测试、上游包测试、双平台 Debug 构建；新增宿主测试覆盖正文往返、清单、表格、撤销、导入、只读、中文组合文本和浅深色／窄布局。隔离应用进行排版、保存和清单联动检查。最低系统运行、真实输入法候选窗口、iOS 全矩阵与真机云同步不以编译或模拟输入代替。
