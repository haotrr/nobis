# 报表扫描优化与万条规模验证

## 边界与方案

用户授权实现与隔离副本验证。工作区起点干净；不操作原始 Minty、正式 Nobis 库、安装及云设置；用户已授权本地提交，不推送。

- 同次报表按全部冲突分支建立年／月索引，月报仅扫描候选期间，非月度收入仍仅计年报。
- CSV、月度图和跨年图复用授权后的投影；通过 ID 字典取得来源，避免数组反复 contains。资产历史按日期／币种分组，期末余额按持有人／币种一次扫描。
- 汇总就地修改币种分组，避免每次追加 sourceIDs 时复制数组。
- 单次 records/reportView 用同一个 Repository 快照校验权限及投影，不保留跨刷新缓存；导出点击时重新授权与读取。
- 保留冻结旧扫描算法作为正确性对照；用 Minty 个人 JSON 副本派生 12,000 条收支／收入记录，仅在新建 Core Data 目录运行。保留金额、日期与分类分布，去掉指向未扩容记录的关联；不把压力样本当作真实账本。
