# 后续计划

更新：2026-10-15。当前为 v0.1 本地开发试用版；已实现能力统一见[功能清单](feature-inventory.md)，验证状态见[验证记录](verification.md)。

## 当前方向

- 保持共同生活为默认、少量内容仅自己可见；不自动扩大旧数据权限。
- 优先完善基础功能与核心流程，保持笔记清单自动联动待办、财务统计与隐私规则。
- 语音播报、盲文、大字号等专项测试与优化暂缓；保留已有适配，未获新的方向调整不主动深入这些专项。
- macOS 14 / iOS 17 为最低部署声明；最低版本实际兼容仍需验收。

## 基础功能优先级

本轮已补齐导入重复来源阻断、无新增不写入、批量投影复用和账本多关键词查找。后续基础缺口按以下顺序推进：

1. 数据核对：财务归属确认、旧本地成员映射预览及资产差额核对已实现；映射后的实际迁入已实现，真实持有范围由用户确认。
2. 数据恢复：已实现隔离恢复、成员映射、差异预览与新增迁入；差异可明确保留目标，其余冲突阻断，提交前备份及过期校验已覆盖。正式库执行和长期恢复演练待单独授权。
3. 日常提醒：本机开关与静默时段已实现；真实后台送达、跨设备及系统时区变化的送达验收后续安排。
4. 大库性能：报表重复全量扫描与 12,000 条规模验证已完成；首次加载及十万条／十万修订验证也已完成；后续关注全库解码、大 payload 与十万条 UI 响应。
