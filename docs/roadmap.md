# 后续计划

更新：2026-10-13。当前为 v0.1 本地开发试用版；已实现能力统一见[功能清单](feature-inventory.md)，验证状态见[验证记录](verification.md)。

## 当前方向

- 保持共同生活为默认、少量内容仅自己可见；不自动扩大旧数据权限。
- 继续原生 UI/UX 打磨，保持笔记清单自动联动待办、财务统计与隐私规则。
- macOS 14 / iOS 17 为最低部署声明；最低版本实际兼容仍需验收。
